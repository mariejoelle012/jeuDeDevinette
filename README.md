# Jeu de Devinettes 

## Description
Jeu en Java où l'ordinateur génère un nombre aléatoire entre 1 et 100.
Le joueur a 10 essais pour le deviner.

## Règles
- Un nombre aléatoire entre 1 et 100 est généré automatiquement
- Le joueur entre un nombre à chaque essai
- Le jeu indique si le nombre est **trop grand** ou **trop petit**
- Le joueur gagne s'il trouve le nombre en 10 essais maximum
- Sinon, le jeu révèle le nombre secret et le joueur perd

## Comment exécuter le projet
1. Cloner le projet :
   git clone https://github.com/TonPseudo/JeuDevinettes
2. Ouvrir avec IntelliJ IDEA
3. Lancer le fichier `Main.java`
